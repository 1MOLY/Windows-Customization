# Windows Customization

My personal settings for 3rd party apps on Windows 11 .

## Tools

* YASB (Statusbar) -> Configs at %USERPROFILE%.config\\yasb\\
* Windhawk (Mods) → Settings-Import per Mod
* FluentFlyout (Volume/Media Flyouts) → XML-Import in the App
* Wallpaper Engine → Steam Workshop, Wallpaper "Purple Eye Anime" (URL in the "Wallpaper-Engine" folder)
